## 배정 기준

1. 외부 컨설팅 위원은 담당 조를 09:30부터 차례로 만납니다.
2. 교내 선생님은 당일 수업 시간과 겹치지 않는 회차에만 배정합니다. 수업 직전·직후 회차도 피합니다.
3. 한 조는 같은 위원을 두 번 만나지 않고, 같은 회차에 두 위원을 만나지 않습니다.
4. 조당 횟수는 수학 4회, 과학 분야 3회를 기본으로 합니다. 분야별 교내 선생님 1인당 평균이 3회 미만이면 조당 4회로 올립니다(생명과학, 융합).
5. 교내 선생님 사이의 횟수는 분야 안에서 최대한 고르게 맞춥니다.
